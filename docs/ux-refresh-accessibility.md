# Akadálymentesség

- Az új fő akciógombok legalább 44 px magasak.
- A kategóriák szekciócímei és elérhetőségi állapotai képernyőolvasóval is értelmezhetők.
- A nagyobb szöveg és az egyszerűsített nézet az új elemekre is kiterjed.
- A csökkentett mozgás beállítás mellett nincs kötelező új animáció.
- Mobilon a mérkőzéstörténet legfeljebb három tömör sort mutat.
