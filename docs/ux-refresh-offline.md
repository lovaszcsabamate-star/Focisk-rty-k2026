# Offline kompatibilitás

Az UX-frissítés kizárólag helyi JavaScript- és CSS-erőforrásokat használ. Az új fájlok bekerültek a service worker előtöltési listájába, a standalone buildbe és az Android-előkészítés által használt webes csomagba. Nem került be külső kép, betűtípus, CDN vagy hálózati API.
